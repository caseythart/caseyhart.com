Approach

Make sure ontology is the right tool for the job. Then use it wisely.

  1. Plan

    Clarify and scope the usecase. Perform independent research and discuss with SMEs. Set clear success criteria.

  2. Build

    Create the ontology, ETL pipelines, and initial queries. Don't forget the tests!

  3. Utilize

    Ensure the model is useful. Have an end to end process that can clearly deliver value.

  4. Hand off

    Document, train, and leave your team able to run it without me.
